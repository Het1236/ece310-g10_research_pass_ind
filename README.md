## Project overview
We are studying pinching antenna systems, a new type of flexible antenna where an antenna element can be turned on at almost any point along a dielectric waveguide. A recent scheme called EDMA splits a waveguide into segments, with one antenna per segment, and relies on line-of-sight blockage to keep segments from interfering with each other. EDMA's limit is that each segment can only serve one user at a time.

Our project asks whether one segment can serve several users at once, using a second, power-domain layer inside the segment, without breaking the blockage-based isolation between segments.
