## What this milestone covers
At this stage we have defined our wireless communication problem, reviewed the papers closest to it, and picked our starting point in the existing work (our SOTA baseline). We have also laid out the early system model code and a plan for the rest of the semester. The full technical analysis, proofs, and simulation results are not part of this milestone and will be built up over the coming milestones.

## Folder contents
- `Report/` — the M1 PDF report: problem statement, literature review, SOTA position, and timeline.
- `Video/` — link to our recorded walkthrough video.
- `Code/` — the early system and channel model code, with instructions to run it.
- `Data/` — notes on how we generate and use simulation data. We do not use an external dataset.
- `Results/` — left mostly empty at this stage. Results will start appearing from Milestone 2 onward.
